react project essentials

# Initialize Vite with the React-TypeScript template (or vanilla JS if you prefer, but we will use standard JS/JSX configurations for absolute compatibility here)
npm create vite@latest denkar-agency -- --template react

# Move into your project directory
cd denkar-agency

# Install core dependencies
npm install react-router-dom framer-motion lucide-react

# Install Tailwind CSS, PostCSS, and Autoprefixer as development dependencies
npm install -D tailwindcss postcss autoprefixer

# Initialize Tailwind configuration files
npm install tailwindcss @tailwindcss/postcss postcss

Then manually create these files.

in root folder 
>postcss.config.js
export default {
  plugins: {
    "@tailwindcss/postcss": {},
  },
}
